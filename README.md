# Layout Spark

A single-file random poster-layout generator inspired by an off-kilter editorial composition.

## Open it

Open `layout-creator web` in any modern web browser. No installation, server, or dependencies are required.

## Use it

1. Choose a **format**: Poster, Square, or Story.
2. Choose a **palette**.
3. Select **Generate layout** to create a new composition.
4. Use **Desktop** or **Mobile** to preview the artwork at each device scale.
5. Select **Dark mode** or **Light mode** for the editor interface.
6. Choose **Download SVG** to save a standalone vector version of the current layout.

## Features

- Randomized logo, headline, product, contact, and accent-element placement
- Responsive editor that works on desktop and mobile browsers
- Mobile preview constrained to a phone-friendly width
- Four color palettes and three artboard formats
- Valid, self-contained SVG exports
- Watermark: `Developed by Htun Thit Oo @ 2026`
